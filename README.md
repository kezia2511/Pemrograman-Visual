PERTEMUAN 1
Pengenalan Pemrograman Visual
Konsep Dasar Pemrograman Visual

Pemrograman visual adalah cara membuat aplikasi dengan menggunakan komponen-komponen grafis untuk membangun tampilan antarmuka. Berbeda dengan pemrograman konvensional yang banyak menggunakan penulisan kode secara manual, pemrograman visual memungkinkan pengembang menyusun tampilan secara langsung.

Perubahan yang dilakukan pada tampilan dapat dilihat dengan lebih cepat. Setelah antarmuka dibuat, setiap komponen dapat diberikan fungsi melalui kode agar aplikasi dapat merespons interaksi dari pengguna.

Perbandingan Pemrograman Konvensional dan Pemrograman Visual
| Aspek              | Pemrograman Konvensional                      | Pemrograman Visual                                 |
| ------------------ | --------------------------------------------- | -------------------------------------------------- |
| Perancangan UI     | Dibuat dengan menulis kode secara manual      | Dibuat dengan menyusun komponen secara visual      |
| Perubahan Tampilan | Perlu menjalankan program untuk melihat hasil | Perubahan dapat langsung terlihat saat perancangan |
| Fokus              | Berfokus pada sintaks dan logika program      | Menggabungkan desain antarmuka dan logika program  |

Ekosistem Teknologi Pendukung
Beberapa teknologi yang mendukung pengembangan pemrograman visual antara lain:
Visual Basic, yaitu bahasa pemrograman yang digunakan untuk membuat aplikasi.
Visual Studio, yaitu lingkungan pengembangan atau IDE untuk merancang tampilan dan menulis kode.
.NET, yaitu framework yang menyediakan berbagai library untuk membantu pengembangan aplikasi.

Kesimpulan
Pemrograman visual mempermudah proses pembuatan aplikasi karena pengembang dapat merancang tampilan menggunakan komponen visual dan menambahkan logika program sesuai kebutuhan.


PERTEMUAN 2
Komponen Visual dan Antarmuka Windows Forms
Eksplorasi Komponen Visual
Pada pertemuan kedua, materi membahas komponen-komponen visual yang digunakan dalam pembuatan aplikasi Windows Forms. Komponen tersebut digunakan untuk membangun antarmuka atau User Interface agar pengguna dapat berinteraksi dengan aplikasi.
Dengan menggunakan Visual Studio, pengembang dapat merancang tampilan aplikasi secara visual dan melihat perubahan yang dilakukan secara langsung.

Komponen Dasar Antarmuka
Beberapa komponen dasar yang digunakan dalam Windows Forms adalah:
Form, berfungsi sebagai jendela atau wadah utama aplikasi.
Label, digunakan untuk menampilkan teks atau informasi.
TextBox, digunakan sebagai tempat pengguna memasukkan data.
Button, digunakan untuk menjalankan suatu perintah ketika diklik.
Komponen-komponen tersebut dapat digabungkan untuk membentuk sebuah antarmuka aplikasi.

Properties dan Event
Setiap komponen memiliki karakteristik dan cara berinteraksi yang berbeda, terutama melalui Properties dan Event.

1. Properties
Properties digunakan untuk mengatur karakteristik suatu komponen. Contohnya:
Name untuk menentukan nama komponen.
Text untuk mengatur tulisan yang ditampilkan.
Size untuk mengatur ukuran.
Location untuk menentukan posisi komponen.
Pengaturan tersebut dapat dilakukan melalui jendela Properties tanpa harus menulis kode secara langsung.

2. Event
Event adalah peristiwa yang terjadi karena adanya interaksi pengguna dengan komponen. Contohnya:
Click, terjadi ketika komponen diklik.
TextChanged, terjadi ketika isi teks berubah.
Event dapat dihubungkan dengan kode agar aplikasi dapat memberikan respons terhadap tindakan pengguna.

Kesimpulan
Windows Forms menggunakan berbagai komponen visual untuk membangun antarmuka aplikasi. Setiap komponen dapat diatur melalui Properties dan diberikan fungsi menggunakan Event sehingga aplikasi dapat berinteraksi dengan pengguna.
